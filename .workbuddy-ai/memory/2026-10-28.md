# 2026-10-28

## Repo exploration: synaxis_health_care

Explored the whole repo for the first time. Findings recorded below so future sessions don't re-derive them.

- Single real project: `stitch_synaxis_health_care_admin_panel/` — React 18 + TS + Vite + Tailwind admin PWA
  ("Synaxis Health Care Admin Terminal") backed directly by Supabase (auth, Postgres, RLS, realtime, Storage).
- Data model: 15+ tables across 7 migrations (`0001`–`0007`), 383 SQL lines. Modules: doctors + monthly
  ledger, customers/vendors debit-credit ledgers, Product Master, purchase orders, partnership A/B
  settlement, warranty invoices, company settings. PDFs via jsPDF + autotable.
- `npm run build` PASSES (`tsc -b && vite build`, ~34s, 2827 modules, ~210 KB main chunk).
- `npm run lint` is BROKEN: no `eslint.config.*` exists anywhere; ESLint 10.9.1 refuses to run.
- Code style is inconsistent: many files are compressed onto a single long line (e.g.
  `WarrantyInvoiceFormPage.tsx` = 8 physical lines but fully implemented), others are normally formatted.
  Do NOT judge completeness by line counts here.
- Docs drift: `PROJECT_DOCUMENTATION.md` claims migrations `0001`–`0006` but `0007_doctor_entry_date.sql`
  exists; it also describes a 12-month area chart while `DashboardPage` actually renders a Recharts **pie** chart.
- Known cruft: duplicate `/warranty` entry in `AppShell` `quickActions`; unused imports in `App.tsx`
  (`SectionPage`, `Box`, `Building2`, `Handshake`, `ShoppingCart`, `Stethoscope`);
  `output/`, `tmp/`, `artifacts/` (incl. 4.9 MB `workbook-audit.json`) are committed to git.
- Repo has no `.env` (only `.env.example`) — app cannot run against Supabase until it is created.
